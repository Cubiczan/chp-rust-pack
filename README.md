# @cubiczan/chp-rust-pack

Installable CHP + Rust finance pack for thought leadership and implementation.

## Install

```bash
npm install @cubiczan/chp-rust-pack
```

## Use

```bash
npx chp-rust-pack show --variant cubiczan
npx chp-rust-pack init ./chp-rust-pack --variant cubiczan
```

## Variants

- `cubiczan`
- `impactquadrant`

## What it writes

- `README.md`
- `IMPLEMENTATION.md`
- `pack.json`
- `assets/landing-page.html`
- `assets/founder-memo.md`
- `assets/post-bank.md`
- `assets/faq.md`

## What to implement

1. Drop the landing page into your CMS or static site.
2. Reuse `pack.json` in your tooling.
3. Publish the memo and post bank.
4. Follow `IMPLEMENTATION.md` for the rollout.
