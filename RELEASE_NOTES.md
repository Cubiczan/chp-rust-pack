# Release Notes

## 0.1.0

- Published `@cubiczan/chp-rust-pack` to npm.
- Added an installable CHP + Rust finance pack with two variants: `cubiczan` and `impactquadrant`.
- Added `chp-rust-pack` CLI scaffolding to generate `README.md`, `IMPLEMENTATION.md`, `pack.json`, and content assets.
- Added landing-page, memo, post-bank, and FAQ generation for implementation-ready rollout.
- Added a public package surface for reuse in marketing and sales workflows.

Install:

```bash
npm install @cubiczan/chp-rust-pack
```

Scaffold:

```bash
npx chp-rust-pack init ./chp-rust-pack --variant cubiczan
```
